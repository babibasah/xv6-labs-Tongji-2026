5. Why does the kernel crash?
The kernel panicked due to a Supervisor Load Page Fault (indicated by scause = 0xd / decimal 13).
The instruction at sepc (0x80002c08) was "lw a3, 0(zero)", which attempted to load 4 bytes from virtual address 0x0 (as recorded in stval = 0x0). 
In xv6, virtual address 0x0 is intentionally left unmapped in the kernel's page table (kernel_pagetable). When the MMU attempted to translate virtual address 0x0, it found no valid Page Table Entry (PTE_V = 0), triggering an unhandled page fault exception in kernel mode. Because the fault occurred in supervisor mode, xv6's kerneltrap() caught the exception and called panic("kerneltrap").
